# 已知问题与验证范围

## 图形与性能

Adreno 750 已完成真实命令提交、内存写回、完成同步和 iOS 桌面渲染，但持续交互仍会明显掉帧；打开应用可能短暂黑屏。单手模式黑色背景和最近任务阴影可能呈紫色，部分文字也可能异常。不能以桌面出现或时钟更新作为完整 GPU 驱动成功的依据。

已修正 Turnip 释放 BO 后再次清零、破坏被其他线程复用对象的竞态。当前对照中粉色块不再出现，命令拒绝和纹理失败显著减少，但卡顿没有解决。此结论限定于对应实机试验，不能扩展为所有图形错误已经修复。

GPU 工厂表包含 231、310、366、422、500、578、629、680、720、770、834、903 MHz。当前基线为诊断对照限制在 500 MHz；先前放开 903 MHz 未解决卡顿。HFI ACK 表示请求获得确认，不等于持续实测时钟。温度反馈与热保护未完成验证。

已尝试软件 120 Hz 通知和独立显示复制线程；物理刷新率、稳定 FPS 和端到端延迟尚未达标或完成测量。CPU 复制 framebuffer 与实际屏幕扫描是不同环节。

## 输入与用户空间

原生 1200×2670 输出与全局键盘宽度适配已经分别在设置、主屏搜索和 App 资源库搜索中确认。触控能工作，但显示与调度瓶颈可能使操作体感迟滞。

墙纸资源、扩展注册和缓存适配只取得部分改善；墙纸预览、应用以及照片应用仍可能空白或黑屏。Safari 和其他系统应用尚未完成系统性兼容验证。

## 启动与恢复

UEFI 的 SCM 初始化存在间歇性停止现象。统一的超时恢复只能覆盖已经建立定时器、异常处理或内核恢复线程的阶段；安全固件调用阻塞、早期 CPU 启动故障或硬件挂死可能仍需要按键返回 OrangeFox。

Recovery 中可用的充电、声音、亮度或 USB 接口不能直接证明 iOS 中的对应服务可用。无线、音频、电源管理、亮度和热保护仍需各自的设备驱动及实机验证。
